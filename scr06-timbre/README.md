# Un timbre con luz

**Sistemas de Control y Robótica I**, UD06. Ficha «Salidas: matriz de LED y sonido».
Ejemplo del libro.

## Abrirlo en MakeCode

1. Entra en [makecode.microbit.org](https://makecode.microbit.org).
2. Pulsa **Importar** y después **Importar URL**.
3. Pega esta dirección y pulsa **Ir**:

   ```
   https://github.com/fmunguia/makecode-fichas/tree/main/scr06-timbre
   ```

El programa se abre con sus bloques.
