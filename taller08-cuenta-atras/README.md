# Cuenta atrás

**Taller de programación y robótica**, UD08. Ficha «Salidas: la pantalla de LED y el sonido».
Ejemplo del libro.

## Abrirlo en MakeCode

1. Entra en [makecode.microbit.org](https://makecode.microbit.org).
2. Pulsa **Importar** y después **Importar URL**.
3. Pega esta dirección y pulsa **Ir**:

   ```
   https://github.com/fmunguia/makecode-fichas/tree/main/taller08-cuenta-atras
   ```

El programa se abre con sus bloques.
