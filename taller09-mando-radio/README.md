# Un mando a distancia por radio

**Taller de programación y robótica**, UD09. Práctica con herramientas «Un mando a distancia por radio».
Práctica con herramientas (solución para el profesor).

## Abrirlo en MakeCode

1. Entra en [makecode.microbit.org](https://makecode.microbit.org).
2. Pulsa **Importar** y después **Importar URL**.
3. Pega esta dirección y pulsa **Ir**:

   ```
   https://github.com/fmunguia/makecode-fichas/tree/main/taller09-mando-radio
   ```

El programa se abre con sus bloques.

> El grupo (1) es un ejemplo: cada pareja pone el número que le da el profesor.
