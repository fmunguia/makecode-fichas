# Proyectos de MakeCode de las fichas

Programas de MakeCode (micro:bit) de los libros del Colegio Puente
*Sistemas de Control y Robótica I* y *Taller de programación y robótica*.
Cada carpeta es un proyecto: el que aparece dibujado en la ficha, con sus bloques.

## Cómo se abre un proyecto

- **Desde el libro**: escanea o pulsa el código QR que hay debajo del programa. Se abre directamente en MakeCode.
- **Desde aquí**: pulsa «MakeCode» en la tabla de abajo.
- **En MakeCode**: [makecode.microbit.org](https://makecode.microbit.org) › **Importar** › **Importar URL**
  y pega la dirección de la carpeta, por ejemplo
  `https://github.com/fmunguia/makecode-fichas/tree/main/scr06-timbre`.

No hace falta iniciar sesión. Lo que cambies se guarda en tu navegador, como cualquier proyecto de MakeCode.

Los enlaces directos (`https://makecode.microbit.org/#pub:_…`) los crea el workflow
**Compartir en MakeCode** cada vez que cambia un proyecto, igual que el botón «Compartir» de
MakeCode, y quedan en `enlaces.json` y `enlaces.tex`. Si cambia alguno, hay que copiar
`enlaces.tex` en `comun/makecode-enlaces.tex` del repositorio de los libros.

## Cómo están hechos

Cada carpeta tiene `main.ts` (el programa en JavaScript), `main.blocks` (los mismos bloques
colocados) y `pxt.json` (nombre y extensiones). Las extensiones van fijadas a una versión:
Nezha `v1.3.11` y PlanetX `v1.6.10`.

Cada cambio se compila en GitHub Actions con el compilador de MakeCode (`pxt build`), y del
resultado salen los archivos `.hex` para pasar directamente a la placa (pestaña **Actions**,
artefacto `hex`).
