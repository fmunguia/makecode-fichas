# Arregla la lámpara

**Taller de programación y robótica**, UD08. Ficha «Entradas: botones, luz y temperatura» (actividad nueva).
Actividad «Arregla el programa»: tiene un error a propósito.

## Abrirlo en MakeCode

1. Entra en [makecode.microbit.org](https://makecode.microbit.org).
2. Pulsa **Importar** y después **Importar URL**.
3. Pega esta dirección y pulsa **Ir**:

   ```
   https://github.com/fmunguia/makecode-fichas/tree/main/taller08-arregla-lampara
   ```

El programa se abre con sus bloques.
