# Placa robot (grupo 7)

**Sistemas de Control y Robótica I**, UD10. Ficha «Radio y Bluetooth con Micro:Bit».
Ejemplo del libro.

## Abrirlo en MakeCode

1. Entra en [makecode.microbit.org](https://makecode.microbit.org).
2. Pulsa **Importar** y después **Importar URL**.
3. Pega esta dirección y pulsa **Ir**:

   ```
   https://github.com/fmunguia/makecode-fichas/tree/main/scr10-robot-radio
   ```

El programa se abre con sus bloques, y MakeCode añade solo las extensiones que usa: Nezha (`pxt-nezha`, de ELECFREAKS).
