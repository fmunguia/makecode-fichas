# Un medidor de luz con barras

**Sistemas de Control y Robótica I**, UD06. Práctica con herramientas «Un medidor de luz con barras».
Práctica con herramientas (solución para el profesor).

## Abrirlo en MakeCode

1. Entra en [makecode.microbit.org](https://makecode.microbit.org).
2. Pulsa **Importar** y después **Importar URL**.
3. Pega esta dirección y pulsa **Ir**:

   ```
   https://github.com/fmunguia/makecode-fichas/tree/main/scr06-medidor-luz
   ```

El programa se abre con sus bloques.
