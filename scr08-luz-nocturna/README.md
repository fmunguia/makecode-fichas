# Luz nocturna: leer un sensor y encender un actuador

**Sistemas de Control y Robótica I**, UD08. Paso a paso «Leer un sensor y encender un actuador» y práctica «Luz nocturna».
Ejemplo del libro.

## Abrirlo en MakeCode

1. Entra en [makecode.microbit.org](https://makecode.microbit.org).
2. Pulsa **Importar** y después **Importar URL**.
3. Pega esta dirección y pulsa **Ir**:

   ```
   https://github.com/fmunguia/makecode-fichas/tree/main/scr08-luz-nocturna
   ```

El programa se abre con sus bloques.
