# Emisor (radio, grupo 7)

**Taller de programación y robótica**, UD09. Ficha «Comunicación por radio».
Ejemplo del libro.

## Abrirlo en MakeCode

1. Entra en [makecode.microbit.org](https://makecode.microbit.org).
2. Pulsa **Importar** y después **Importar URL**.
3. Pega esta dirección y pulsa **Ir**:

   ```
   https://github.com/fmunguia/makecode-fichas/tree/main/taller09-emisor
   ```

El programa se abre con sus bloques.
