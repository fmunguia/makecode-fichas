# Un dado electrónico

**Sistemas de Control y Robótica I**, UD06. Paso a paso «Un dado electrónico con Micro:Bit».
Ejemplo del libro.

## Abrirlo en MakeCode

1. Entra en [makecode.microbit.org](https://makecode.microbit.org).
2. Pulsa **Importar** y después **Importar URL**.
3. Pega esta dirección y pulsa **Ir**:

   ```
   https://github.com/fmunguia/makecode-fichas/tree/main/scr06-dado
   ```

El programa se abre con sus bloques.
