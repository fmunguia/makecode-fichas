# El robot que no choca

**Taller de programación y robótica**, UD10. Práctica con herramientas «El robot que no choca».
Práctica con herramientas (solución para el profesor).

## Abrirlo en MakeCode

1. Entra en [makecode.microbit.org](https://makecode.microbit.org).
2. Pulsa **Importar** y después **Importar URL**.
3. Pega esta dirección y pulsa **Ir**:

   ```
   https://github.com/fmunguia/makecode-fichas/tree/main/taller10-robot-no-choca
   ```

El programa se abre con sus bloques, y MakeCode añade solo las extensiones que usa: Nezha (`pxt-nezha`, de ELECFREAKS) y PlanetX (`pxt-PlanetX`, para el sensor de ultrasonidos).

> Como en el resto de la unidad, el Nezha avanza con M1 y M2 de signo contrario (los motores están uno frente al otro) y gira sobre sí mismo con el mismo signo.
