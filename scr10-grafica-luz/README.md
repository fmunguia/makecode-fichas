# Ver la luz que mide la placa

**Sistemas de Control y Robótica I**, UD10. Ficha «El puerto serie».
Ejemplo del libro.

## Abrirlo en MakeCode

1. Entra en [makecode.microbit.org](https://makecode.microbit.org).
2. Pulsa **Importar** y después **Importar URL**.
3. Pega esta dirección y pulsa **Ir**:

   ```
   https://github.com/fmunguia/makecode-fichas/tree/main/scr10-grafica-luz
   ```

El programa se abre con sus bloques.
